# SuperCopy (Remake Version)

クリップボードを自動監視して履歴を蓄積し、一括でコピーできるミニマルなプロ用ツール。
React + Electron + Tailwind CSS によってリメイクされました。

## 特長
*   **改行自動整形**: コピーしたテキストに改行(`\r\n`, `\n`)が含まれていても、自動的にスペースに置換して1行の履歴として安全に保存・表示します。
*   **モダンなUI**: Tailwind CSS と Framer Motion を使用したスムーズなアニメーションとダークアクリル風のデザイン。
*   **フレームレスウィンドウ**: 独自実装のタイトルバーによるドラッグ移動、最大化時の軽量化。
*   **完全な責務分離**: Mainプロセス（クリップボード監視）とRendererプロセス（UI）の境界を分離。

## 動作環境・開発環境
*   Node.js 18+
*   Vite
*   React 18
*   Electron 30+

## 開発とビルド

```bash
# 依存関係のインストール
npm install

# 開発モードでの起動（HMR対応）
npm run dev

# ビルド（本番用exeの生成などへ繋げる）
npm run build
```

## 使い方
1. アプリを起動すると、自動的にクリップボードの監視を開始します。
2. 他のアプリでテキストをコピーすると、リストに追加されます（重複や空白は自動スキップ）。
3. 画面下部の「一括コピー」を押すと、現在表示されているリスト全体が改行区切りでクリップボードにコピーされます。
4. 「クリア」を押すと履歴がリセットされます。
